---
question: "What's the difference between the different versions of OurDNA?"
---

The OurDNA v4.1 data set contains 730,947 exomes plus the 76,215 genomes previously called OurDNA v3.1, all mapped to the GRCh38/hg38 reference sequence.

The OurDNA v2.1 data set contained data from 125,748 exomes and 15,708 whole genomes, all mapped to the GRCh37/hg19 reference sequence. Most of the data from v2 are included in v4.1.
